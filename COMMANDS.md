# GSEA Faculty Portal — Quick Command Reference

### Build & Styles
- `npm run build`: Compiles Tailwind CSS v4 minified into `output.css`.
- `npm run dev:css`: Watches `src/input.css` for live class updates.
- `npm run serve`: Launches local HTTP preview on port 8080.

### Remote Sync
- Say **"Commit"** or **"Commit changes"**: Automatically commits and pushes to GitHub (`origin/main`) in one atomic step.
